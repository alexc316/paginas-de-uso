# Generador de Códigos QR Pro

Una herramienta web ligera, moderna y 100% interactiva creada con HTML, CSS y JavaScript para generar códigos QR personalizados al instante desde cualquier navegador, sin necesidad de instalar programas ni registrarse.

---

## Características Principales

* **Generación en Tiempo Real:** El código QR se actualiza automáticamente conforme escribes o pegas tu texto, enlace o información.
* **Personalización de Colores:** Cambia el color del código QR y del fondo a tu gusto para darle un toque único.
* **Descarga Directa:** Guarda tu código QR generado en formato de imagen PNG de alta calidad con un solo clic.
* **Diseño Responsivo:** Funciona perfectamente tanto en computadoras como en teléfonos móviles.

---

## Cómo usarlo localmente

Si quieres probar o modificar el proyecto en tu computadora:

1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto en **Visual Studio Code**.
3. Abre el archivo `index.html` en tu navegador web haciendo doble clic, o utiliza la extensión **Live Server** para verlo en vivo.
